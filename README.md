# Satsuma Front Window Tint

Мод для My Summer Car.

## Что делает

- Добавляет в магазин Теймо товар **«Тонировка передних стёкол»**.
- Цена: **500 mk**.
- Покупка красит два передних боковых стекла.
- Лобовое, задние и форточки намеренно исключаются.
- Покупка сохраняется через unified SaveLoad MSCLoader.
- Повторная покупка разрешена и повторно применяет тонировку.

## Важно

В коде поиск передних стёкол сделан по именам объектов в иерархии `SATSUMA`.
Это сделано потому, что названия объектов находятся в игровых ассетах, а не в Assembly-CSharp.dll.

Если в твоей сборке стекло называется иначе, нужно будет изменить функцию `IsFrontSideWindow()`.

## Сборка

Открыть `.csproj` в Visual Studio 2022 с .NET Framework 4.7.2 и собрать Release.

Получившийся:

`bin/SatsumaFrontWindowTint.dll`

положить в папку Mods.

Зависимости:
- MSCLoader
- MscModApi
